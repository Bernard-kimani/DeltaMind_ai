# DeltaMind AI

Autonomous options-trading agents for the **Alpaca AI Trading Agents Hackathon** (lablab.ai × Alpaca, Aug 28 – Sep 4, 2026).

Full context, architecture, decisions, setup steps, and the running status log live in **[PLAN.md](PLAN.md)** — read that first, and update it as the project evolves.

- `backend/` — FastAPI + LangGraph multi-agent pipeline, quant engine, Alpaca MCP/REST/CLI integration
- `frontend/` — React + TypeScript live dashboard
